# Cenan AI

Cenan AI resmi web sitesi — indirme, sohbet motoru ve abonelikler.

## Çalıştırma

```bash
npm install
npm run dev
```

## Sayfalar

- `/` — Ana sayfa (CENAN hero + animasyon, kısa klipler, indirme, iletişim)
- `/cenan-ai` — Cenan AI sohbet / arama motoru
- `/abonelikler` — Aylık / yıllık paketler (5 plan)
